# Rusanta Core

Core infrastructure crate for the Rusanta ecosystem.

Rusanta is a Rust-native scientific computing framework designed for:

- numerical computing
- machine learning
- tensor computation
- GPU acceleration


## Features

- Shared error handling
- Common traits
- Backend abstractions
- Runtime utilities
- Foundation types


## Ecosystem

Rusanta consists of:

- rusanta-core
- rusanta-array
- rusanta-frame
- rusanta-tensor
- rusanta-ml
- rusanta-viz
- rusanta-stat-viz
- rusanta-triton
